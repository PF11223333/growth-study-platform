# 公安思维提升：18个原页组入口

本次补充按6种能力、3类题型组织的18个原页组。它们覆盖原书338道题的阅读范围，包含已经单列的13道校准题，不新增338道独立题；其余325道的逐题文字、手写选择、答案及法规解析校准仍未完成。

## 使用方式

每组首屏只显示第一原页，完整原页通过站内阅读器逐页打开。保持情景材料与子题连续阅读，做完后定位该章答案表，按题型、情景序号和原题号核对。原图完整保留红蓝笔迹，可能看到原来作答与订正，因此明确为不计分的原页阅读回忆。

答案页已视觉核对：PDF81、97、127、151、161、171。上一题型末题常延伸到下一题型开始页，例如PDF73先续单选最后题、再开始多选，PDF74先续多选最后题、再开始情景题。新入口将该共用页包含在上一题型范围内，提示读到下一题型标题前停止，防止截断图表和选项。原页坐标不猜测、不把整页误标为精确题框。

## 安装与验证

- 生成脚本：`scripts/build-thinking-page-groups.mjs`。
- 候选：`data/thinking-page-groups-20261106-candidate.json`，`records`为18条新记录；`recordLinkPatches`为6条章节记录的追加关联。
- 使用`mergeImported`合并新记录，章节追加缺失的links，不覆盖正文或人工编辑；根任务统一备份、版本检查及写入。
- 只复用已有媒体，新增媒体体量0。首屏每组1张图。
- 数据验证：原页存在、页码范围、关联记录、无自动答案、判分函数返回null、重复合并零变化、公开字段无路径、生产库未写。
- 单元测试覆盖共用边界页、情景完整范围、无对错记录及同源题关联。

不能把本次“可从刷题界面打开整组”描述成“338道题已逐题精校”，也不能把组数计入独立题正确率。
